# 🏡 House Price Prediction

A machine learning and data analysis project focused on exploring property data and building a predictive model to estimate housing prices.

## 🚀 Features
* **Exploratory Data Analysis (EDA):** Statistical visualization of housing price spreads and distributions.
* **Feature Correlation:** In-depth heatmap analysis identifying the strongest variables that drive property value.
* **Predictive Modeling:** Machine learning implementation evaluating actual vs. predicted house prices for accuracy validation.
* **Visual Insights:** High-quality exported visual assets (Matplotlib/Seaborn) for stakeholder reporting.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn 

## 📂 Repository Contents
* `analysis.ipynb`: The core Jupyter Notebook containing all data cleaning, EDA, and model training.
* `Housing.csv`: The primary dataset utilized for model training and testing.
* `chart1_price_distribution.png`: Histogram detailing the spread of housing prices.
* `chart2_correlation_heatmap.png`: Matrix visualizing the relationships between different housing features.
* `chart3_actual_vs_predicted.png`: Scatter plot demonstrating the predictive accuracy of the final model.
